# 팜넷 문서발행 시스템 — 웹 링크로 만들기

지금까지는 HTML 파일을 각자 내려받아 열고 URL·팀 코드를 입력하는 방식이었습니다.
아래 절차를 마치면 **링크 하나만 공유**하면 되고, 팀원은 접속 즉시 공용 원장에
자동 연결됩니다. 별도 설정 입력이 필요 없습니다.

## 1. Apps Script에 화면 파일 추가

1. 원장 구글 시트에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 왼쪽 파일 목록의 **＋ → HTML**을 누릅니다.
3. 파일 이름을 **`index`** 로 입력합니다. (확장자 `.html`은 자동으로 붙습니다.
   반드시 `index`여야 합니다.)
4. 새로 만들어진 `index.html`의 내용을 **전부 지우고**, 함께 드린 `index.html`
   파일의 내용을 그대로 붙여넣습니다.
5. 저장합니다.

## 2. Code.gs 갱신

1. `Code.gs`를 열어 내용을 전부 지우고, 함께 드린 최신 `Code.gs`를 붙여넣습니다.
2. `TEAM_CODE` 값이 기존에 쓰던 값과 같은지 확인합니다.
3. 저장합니다.

## 3. 재배포

1. 오른쪽 위 **배포 → 배포 관리**를 엽니다.
2. 기존 배포의 **편집(연필 아이콘)**을 누릅니다.
3. 버전을 **새 버전**으로 바꾸고 **배포**를 누릅니다.
4. 액세스 권한이 **모든 사용자**인지 다시 확인합니다.

## 4. 공유

배포 화면에 나오는 **웹 앱 URL** (`.../exec`로 끝나는 주소)이 곧 프로그램 주소입니다.
이 링크를 팀에 공유하면 끝입니다. 브라우저에서 열면 바로 발행 화면이 뜨고,
상단 표시가 자동으로 초록색 `공용 원장 연결됨`이 됩니다.

즐겨찾기에 등록하거나, 사내 노션 페이지에 링크로 걸어 두면 접근이 편합니다.

## 참고 사항

**앞으로 화면을 수정할 때**
`index.html` 내용만 교체하고 3번(재배포)을 다시 하면 전원에게 즉시 반영됩니다.
팀원이 파일을 새로 받을 필요가 없어지는 것이 이 방식의 가장 큰 장점입니다.

**접근 권한**
링크를 아는 사람은 누구나 접속할 수 있습니다. 사내 공유 범위를 넘기지 마세요.
구글 계정 로그인을 강제하고 싶다면 배포 시 액세스 권한을
'Google 계정이 있는 모든 사용자'로 바꿀 수 있는데, 이 경우 화면은 정상 동작하지만
외부에서 파일로 여는 방식은 더 이상 쓸 수 없습니다.

**기존 HTML 파일도 계속 씁니다**
`famnet-document-issuer.html`은 그대로 두셔도 됩니다. 파일로 열면 예전처럼
URL·팀 코드를 입력해 연결하는 방식으로 동작하므로, 인터넷이 불안정할 때
대비책으로 남겨 두기 좋습니다.

**속도**
Apps Script가 화면을 띄우므로 첫 로딩이 1~3초 걸릴 수 있습니다.
두 번째부터는 빨라집니다.
