# 팜넷 문서발행 시스템

견적서·거래명세서·발주서·원산지증명서를 발행하고, 발행 이력을 팀 공용
구글 시트 원장에 남기는 사내 도구.

## 빠른 시작

```bash
node build/build.js       # dist/index.html 생성
```

빌드 산출물을 Apps Script 에 붙여넣는 방식으로 배포한다. 자세한 절차와
이 프로젝트의 제약 조건은 [CLAUDE.md](./CLAUDE.md) 참고.

## 기능

- **문서 4종** 견적서(단가형/총액형), 거래명세서, 발주서, 원산지증명서
- **부가세 처리** VAT 포함 / 별도 / 면세 / 영세율
- **문서번호 자동 채번** 서버에서 잠금 처리하므로 동시 발행에도 중복 없음
- **발행 기록** 팀 전원이 같은 원장을 보고, 건별 메모를 남길 수 있음
- **열 커스터마이즈** 이름 변경, 너비 드래그, 숫자/텍스트 형식 전환
- **담당자 명부** 담당자·전화번호·이메일을 세트로 저장해 재사용
- **도장 이미지** 업로드해 문서에 적용
- **PDF 출력** 브라우저 인쇄로 A4 규격 그대로 저장
- **반응형** 데스크톱 2단 / 태블릿·모바일 1단, 모바일에서 품목은 카드형

## 구성

| 경로 | 설명 |
|---|---|
| `src/index.html` | 화면 전체. 편집은 여기서 한다 |
| `src/fonts/` | 서브셋한 A고딕 woff2 (400/700) |
| `src/img/` | 팜넷 로고 |
| `apps-script/Code.gs` | 서버. 채번·원장·담당자 명부 |
| `build/build.js` | 폰트·로고 인라인 빌드 |
| `dist/index.html` | 배포본. 직접 편집하지 말 것 |
| `docs/` | 배포·폰트 서브셋 안내 |

## 아키텍처

```
브라우저 (Apps Script 웹앱으로 서빙되는 단일 HTML)
   │
   │  google.script.run  (웹앱 경로)
   │  fetch + 팀 코드     (파일 직접 열기 폴백)
   ▼
Apps Script (Code.gs) ── 실행 주체: 소유자 계정
   │
   ▼
구글 시트 ── 발행기록 / 담당자
```

접속자는 시트 권한이 없어도 된다. 스크립트가 소유자 권한으로 대신 읽고 쓴다.

## 제약

- Apps Script 웹앱은 외부 정적 파일을 서빙하지 못한다. 모든 자원이 단일
  HTML 에 인라인되어야 한다 (그래서 빌드 단계가 있다).
- 배포는 Apps Script 편집기에 붙여넣기 + 새 버전 배포. 저장만으로는
  반영되지 않는다.
